# GitHub CI/CD Node & Repository Management Platform

## Overview

Web application to monitor disk usage of regional CI/CD nodes and to manage the open source repositories assigned to them.
It shows every CI node with its registered repositories and storage indicators, and lets the user register new
repository manifests by searching repositories in real time on the GitHub REST API.

## Features

- Toolbar with the GitHub logo, platform title and an EN/ES language switcher (English by default).
- Material sidenav with "Home" and "New Repository Manifest".
- **Home** (`/home`): "My CI Nodes" grid list with two *CI Node Summary* cards per row. Each card shows the node name and
  location, its repositories (name, full name, allocated GB) and the indicators Total Allocated Storage,
  Available Capacity and Utilization Status (Normal < 75 %, Warning 75 % - 99 %, Critical 100 %).
- **New Repository Manifest** (`/repositories/manifests/new`): reactive form (topic, GitHub repository, CI node,
  allocated size) with cross validation: the size must be greater than 0 and not exceed the available capacity of the
  selected node. `registeredAt` is set automatically (ISO string) and the id is generated by the API.
- Page-not-found view for unsupported routes with a button back to Home.
- Dark, GitHub-like interface on top of an Angular Material prebuilt theme; ARIA attributes and responsive layout.

## Stack

Angular 22 (standalone components, Signals, Router, HttpClient), Angular Material, @ngx-translate/core and
http-loader, TypeScript, RxJS, json-server 0.17.4 (fake API).

## Architecture

Domain-driven, layered and component-based. Bounded contexts under `src/app`:

- `shared`: base assembler/endpoint, layout, language switcher, home and page-not-found views.
- `cinodes`: CI nodes and repository manifests (`domain`, `application`, `infrastructure`, `presentation`).
- `topics`: external GitHub API (repositories found by topic).

Patterns: Request/Response, Resource, Assembler, Api, Endpoint and Store (Angular Signals).

## Configuration and run

```bash
npm install
npm run api     # fake API at http://localhost:3000 (uses server/db.json)
npm start       # app at http://localhost:4200
```

URLs and endpoint paths are defined in `src/environments/`. The GitHub search API is called without authentication
(rate limited to 10 requests per minute).
